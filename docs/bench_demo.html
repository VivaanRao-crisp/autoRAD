autoRAD bench rig: how it moves

Drag the slider or press Play. One cord is tied to a fixed hook. As the attachment moves down, the cord pulls the carriage down, and the carriage pulls both handles open through two links. There are no gears. Numbers come from params.py, using the same equations as bench_check.py.

Behind the board: the cord

Seen through the board from the front. The cord makes 4 vertical runs between the carriage bearings (M1, M2) and the fixed bearings (F0, F1). Solid = near lane, dashed = far lane.

Included angle vs travel

Solid: what the linkage gives. Dashed: a perfectly linear 50° → 110°. The largest difference is about 1°.

  1. Cord pays out. The hook stays put and the attachment moves down 300 mm, so 300 mm of cord comes off the board.
  2. Carriage moves ¼ as far. The cord runs 4 times between the carriage and the fixed bearings, so the carriage slides down 75 mm.
  3. One pin pulls both links. Both links hang from the same carriage pin, so the two handles always match.
  4. Bell cranks rotate. The links pull the drive arms down and inward. Each handle turns 30° about its pivot.
  5. The band closes it. Going back up, the band pulls the carriage up again, takes the cord back in and closes the handles.

This is a 2D picture of the verified kinematics, not a test result. Bolts, washers and the board's thickness are left out. Plate layers (front to back): handle R, link R, link L, handle L.
