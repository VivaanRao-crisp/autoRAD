# autoRAD bench rig — buy list

Everything is hardware-store grade; no part numbers. Quantities include no spares — add 20 %.
Where delivery is a risk, the "local substitute" column works for a bench demo.

Tools: drill with Ø5.5 and Ø8.5 bits (slots: drill a row of Ø5.5 holes and file to 5.3 wide, or
route), hacksaw, screwdrivers, M5/M8 spanners, ruler, protractor, a spring balance 0–10 N if you
can (for the force measurement; a kitchen scale pulling the cord works too).

If the bearings cannot be sourced in time: print plain pulleys Ø16 × 7 with a Ø5.3 bore on the
same bolts (the CAD people add one model). Friction rises; the demo still works.
